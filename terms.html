ESPORTS CAFE 5G 利用規約

ESPORTS CAFE 5G（以下「当店」といいます。）が提供するサービスに関し、会員と当店との間の権利義務関係を定めるものです。会員は、本規約に同意のうえ本サービスを利用するものとします。

第1章　総則

第1条（適用）

1. 本規約は、会員と当店との間の本サービス利用に関わる一切の関係に適用されます。

2. 当店は本規約のほか、利用ルール、ガイドライン、重要事項説明等（以下「個別規定」といいます。）を別途定めることがあります。個別規定は名称にかかわらず本規約の一部を構成します。

3. 本規約と個別規定が矛盾する場合、個別規定が優先されます。

第2章　会員

第2条（利用登録）

1. 登録希望者が本規約に同意の上、当店所定の方法で申請し、当店が承認することにより、会員登録が成立します。

2. 当店は以下に該当する場合、登録を承認しないことがあります。

（1）登録内容に虚偽、誤記または記載漏れがある場合

（2）過去に会員登録の抹消または利用停止処分を受けたことがある場合

（3）暴力団その他の反社会的勢力に該当し、またはこれらと関係を有する場合

（4）その他、当店が客観的かつ合理的な理由により、会員登録を不適当と判断した場合

3. 当店は承認拒否理由を開示する義務を負いません。

4. 未成年者が会員登録またはストアポイントの購入その他有償サービスの利用を行う場合は、あらかじめ親権者その他法定代理人の同意を得るものとします。当店は、必要に応じて、親権者等の同意書、連絡先その他同意を確認するために必要な資料の提出を求めることがあります。

5. 親権者等の同意を確認できない場合、当店は、会員登録、ストアポイントの購入または有償サービスの利用をお断りすることがあります。

第3条（本人確認）

1. 会員登録時および必要に応じて、氏名、住所、生年月日その他本人を確認するために必要な事項を確認できる本人確認書類（運転免許証、マイナンバーカードの表面、パスポート、在留カード、資格確認書、学生証その他当店が認める書類）の提示を求めることがあります。

2. 顔写真のない本人確認書類の場合、当店は、追加の本人確認書類の提示を求めることがあります。

3. 会員が前二項に基づく本人確認に応じない場合、当店は、会員登録を承認せず、または本サービスの利用停止もしくは会員登録の抹消を行うことがあります。

第4条（個人情報の取扱い）

1. 当店は、会員から取得した氏名、住所、生年月日、電話番号、メールアドレスその他の個人情報を、別途定めるプライバシーポリシーに基づき適切に取り扱います。

2. 会員は、本サービスの利用にあたり、当店のプライバシーポリシーの内容を確認するものとします。

3. プライバシーポリシーの詳細は、当店Webサイトまたは店内掲示をご確認ください。

4. 当店は、法令に基づく場合その他個人情報保護法上認められる場合を除き、あらかじめ本人の同意を得ることなく、会員の個人データを第三者に提供しません。

5. 当店は、利用目的の達成、法令上の義務の履行、紛争への対応その他運営上必要な範囲において、会員情報を保管します。保管の必要がなくなった個人情報については、法令およびプライバシーポリシーに従い、消去または適切な方法により処分します。

第5条（ユーザーID・パスワード管理）

1. 会員は、自己責任においてユーザーIDおよびパスワードを管理するものとします。

2. 会員は、第三者への貸与、譲渡、共有を行ってはなりません。

3. ユーザーIDおよびパスワードを利用したログインは、すべて会員本人による利用とみなします。

4. 会員の管理不十分、使用上の過誤または第三者による不正使用等により生じた損害について、当店は責任を負いません。ただし、当店の故意または過失による場合は、この限りではありません。

5. 会員は、登録したメールアドレスおよび電話番号を常に最新の状態に保つものとします。変更があった場合は、速やかに当店所定の手続きにより更新してください。

6. 会員は、ログインに必要なメールアドレス、電話番号またはパスワード等を忘れた場合、当店所定の本人確認手続きを行うことにより、アカウント情報の確認またはパスワードの再設定を受けることができます。本人確認ができない場合、当店は対応をお断りすることがあります。

第3章　ポイント・料金

第6条（ストアポイントの購入および取扱い）

1. 会員は、当店所定の方法により、PC利用料金の支払いに使用するための「ストアポイント」を購入することができます。

2. ストアポイントは、当店が提供するPC利用料金の支払いにのみ使用することができ、現金への換金、第三者への譲渡、会員間での移転または払戻しはできません。

3. ストアポイントの購入後は、会員都合による返品、取消しまたは払戻しには応じません。ただし、法令により払戻しが必要となる場合は、この限りではありません。

4. 当店の責に帰すべき事由によりPC利用サービスの提供が著しく困難となった場合、当店は、法令および当店所定の方法に従い、未使用の有償ストアポイントについて、払戻しまたは代替措置を行うことがあります。なお、キャンペーン、特典その他の理由により無償で付与されたボーナスポイントは対象外とします。

5. クレジットカード会社その他決済事業者によりストアポイントの購入代金の取消し、返金またはチャージバックが行われた場合、当店は、当該購入に対応するストアポイントを取り消し、または失効させることがあります。すでに当該ストアポイントが使用されている場合、会員は、当店に生じた合理的な損害を賠償するものとします。

6. ストアポイントの消費レートは、利用するPCの種類、性能、座席区分その他当店が定める条件に応じて異なります。各PCに適用される消費レートは、店内表示または当店Webサイト等で案内します。

7. 当店は、設備の更新、サービス内容の変更、運営上の必要性その他合理的な理由がある場合、変更内容および適用開始日を、あらかじめ店内表示、当店Webサイトその他適切な方法により周知したうえで、ストアポイントの消費レートを変更することがあります。

第7条（ストアポイントの有効期限）

1. ストアポイントの有効期限は、最終利用日から24か月とします。

2. 「最終利用日」とは、ストアポイントの購入またはストアポイントを使用した最終の日をいいます。ただし、当店が無償で付与するボーナスポイントについては、別途異なる有効期限を定めることがあります。

3. 有効期限を経過したストアポイントは失効し、利用、換金または払戻しを行うことはできません。

4. 当店は、社会情勢、サービス内容または運営上の必要性その他相当の事由がある場合、有効期限の起算日、期間その他の条件を変更することがあります。

5. 会員に不利益となる変更を行う場合は、原則として変更予定日の1年以上前までに、店内掲示、当店Webサイトその他適切な方法により変更内容および適用開始日を告知します。

6. 変更前に取得された有償ストアポイントについて会員に不利益となる変更を適用する場合は、法令に従い、変更の必要性および相当性を考慮した合理的な経過措置を設けるものとします。

第8条（利用料金）

本サービスの料金体系、料金の算出方法その他の利用条件は、当店が別途定め、店内掲示または当店Webサイトへの掲載その他適切な方法により案内します。

第4章　会員の義務

第9条（禁止行為）

会員は、本サービスの利用にあたり、以下の行為を行ってはなりません。

1. 法令または公序良俗に違反する行為

2. 犯罪行為または犯罪行為に関連する行為

3. 喫煙席以外での喫煙、未成年者の喫煙・飲酒、泥酔状態での入店、万引き、置き引き、その他違法行為

4. 東京都青少年の健全な育成に関する条例その他関係法令に基づき、18歳未満の者が午後11時から翌午前4時までの間に当店へ入店し、または店内に滞在する行為

5. 販売商品以外の備品、設備等を持ち帰る行為

6. 他の会員のアカウントを故意・過失にかかわらず利用する行為、アカウントの貸与、共有、複数同時ログイン

7. 店内PCへの無断ソフトウェアインストール、設定変更、無線機器の持ち込み

8. アダルトサイト、アダルトコンテンツの利用

9. P2P等による大量データ送受信、迷惑行為、不正通信、スパム送信、プライバシー侵害

10. 正当な利用手続きを行わず、または利用料金を支払わずに店内に滞在する行為

11. 店内でのみだらな行為

12. 店内での宣伝、勧誘、ナンパ行為、賭け行為、暴力行為

13. 危険物の持ち込み

14. 店内での無断撮影、録音、ライブ配信

15. 著しく不潔な状態または強い悪臭を発する状態で利用し、他の会員または店舗運営に支障を与える行為

16. 当店、他ユーザーまたは第三者のサーバーまたはネットワーク機能を妨害する行為

17. 当店サービスの運営を妨害する行為

18. 不正アクセス、またはこれを試みる行為

19. 不正な目的での利用

20. 他の会員または第三者に不利益、損害、不快感を与える行為

21. 反社会的勢力に対し、直接または間接に利益を供与する行為

22. チートツール、不正プログラムその他ゲーム運営会社または外部サービス提供者が禁止するソフトウェアもしくはサービスを利用する行為

23. 他の会員または当店スタッフに対する暴言、脅迫、誹謗中傷、嫌がらせ、つきまといその他のハラスメント行為

24. 利用料金を支払うことなく長時間座席を占有し、または荷物等を置いたまま長時間離席することにより、他の利用者の利用を妨げる行為

25. 前各号のほか、当店の安全、秩序または円滑な運営を害し、またはそのおそれがあると当店が合理的に判断する行為

第5章　運営管理

第10条（備品の貸出）

1. 当店は、コントローラーやケーブル等の備品（以下「貸出品」といいます。）の貸出を行う場合があります。

2. 貸出品の利用に際しては、本人確認書類の提示、会員情報の確認、貸出記録への署名、預り金の支払いその他当店所定の手続きをお願いすることがあります。

3. 当店は、本人確認書類の原本を貸出品返却までの担保として保管しません。ただし、本人確認のため、一時的に提示を受けることがあります。

4. 貸出品の紛失、破損または無断での持ち帰りが確認された場合、会員は、修理費または同等品の再調達に要する合理的な実費を賠償するものとします。

第11条（ネットワークおよびアカウント管理）

1. 店内PCにログインするオンラインゲームアカウント、SNS等の管理は会員の責任とします。

2. 利用終了後は必ずログアウトしてください。会員のログアウト忘れにより生じた損害について、当店は責任を負いません。ただし、当店の故意または過失による場合は、この限りではありません。

3. 店内PCの設定変更、無断インストールを禁止します。

4. 店内PC内に保存されたデータは、メンテナンスその他運営上の必要に応じて、予告なく削除される場合があります。会員は必要なデータを自己の責任で保存・管理するものとします。

5. 外部サービス（オンラインゲーム、SNSその他第三者が提供するサービス）のアカウント管理および利用は、会員自身の責任とします。当該サービスの利用規約違反、仕様変更、障害、メンテナンス、提供停止またはサービス終了等により、アカウントが停止、制限もしくは削除され、またはサービスを利用できない場合であっても、当店の責に帰すべき事由がある場合を除き、当店は責任を負いません。

第12条（撮影・録音・ライブ配信）

1. 店内での撮影、録音、ライブ配信は事前許可制とします。

2. 他の利用者を撮影する場合、本人の同意が必要です。

3. 商業目的、広告宣伝目的その他営利を目的とする撮影は、当店が別途承諾した場合を除き禁止します。

4. 無断撮影、録音またはライブ配信が判明した場合、当店は、当該行為の中止、撮影データ等の削除の要請、利用停止、退店要求または会員登録の抹消を行うことがあります。

第13条（防犯カメラ）

1. 当店は、防犯、安全管理、事故およびトラブルの確認等を目的として、店内に防犯カメラを設置し、映像を録画します。

2. 録画データは、防犯、安全管理、事故およびトラブルへの対応、法令に基づく対応その他正当な目的の範囲内で使用します。

3. 録画データは、法令に基づく場合その他個人情報保護法上認められる場合を除き、あらかじめ本人の同意を得ることなく第三者に提供しません。

4. 録画データは、当店がプライバシーポリシーその他店内掲示により定める保存期間を経過した後、事故、紛争、捜査対応その他保存する合理的な必要がある場合を除き、順次削除します。

第14条（忘れ物）

1. 忘れ物は、遺失物法その他関係法令および当店所定の取扱基準に従って取り扱います。

2. 法令上認められる保管期間または処理期間を経過した忘れ物については、廃棄、売却、引渡しその他法令に従った方法により処分することがあります。

3. 飲食物その他衛生上保管が困難な物については、保管期間にかかわらず処分することがあります。

4. 当店から忘れ物に関する個別の連絡は原則として行いません。利用者は自己の責任においてお問い合わせください。

第15条（設備等の破損・損害賠償）

1. 会員の故意または過失により、店内の設備、備品、PC、モニターその他当店所有物に損害が生じた場合、当店は修理費、交換費その他当該損害に係る実費を請求することがあります。

第6章　退会・利用停止

第16条（利用停止・登録抹消）

1. 会員が本規約に違反した場合、利用料金その他の支払いを怠った場合、登録情報に虚偽がある場合、またはその他客観的かつ合理的な理由により会員として不適当であると当店が判断した場合、当店は、事前に通知することなく、本サービスの利用停止、退店要求または会員登録の抹消を行うことがあります。

2. 前項の措置が、本規約および法令に従い、会員の責に帰すべき事由に基づいて適切に行われた場合、当店は、当該措置により会員に生じた損害について責任を負いません。ただし、当店の故意または過失による場合は、この限りではありません。

第17条（退会）

1. 会員は、当店所定の手続きにより退会することができます。

2. 退会した場合、会員が保有するストアポイントおよびボーナスポイントは失効し、払戻しまたは第三者への移行は行いません。ただし、法令により払戻しが必要となる場合は、この限りではありません。

3. 会員資格は会員本人に専属するものであり、第三者への譲渡、承継または相続の対象とはなりません。

4. 退会後の会員情報については、法令およびプライバシーポリシーに従って取り扱います。
